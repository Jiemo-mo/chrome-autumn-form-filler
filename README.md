# 秋招网申表单助手

一个基于 Chrome Manifest V3 的本地化网申表单辅助插件，面向秋招、校招、实习投递和企业官网网申场景。

项目定位是：**本地隐私资料库 + 简历解析 + 多版本资料管理 + 人工确认式安全填表**。  
它不是自动投递脚本，不做自动提交、自动保存、自动下一步或自动翻页。

## 功能亮点

- **本地资料管理**：支持基础信息、教育经历、实习经历、项目经历、获奖证书、家庭成员、自我评价
- **多版本简历**：可维护不同岗位、不同公司、不同投递方向的资料版本
- **本地简历解析**：支持导入 `.txt`、`.md`、插件 `.json`，解析后生成可编辑资料版本
- **安全侧边栏填充**：先点击网页目标输入框，再点击侧边栏资料项填入
- **填充前预览**：扫描页面字段，展示拟匹配内容和置信度，用户勾选后再填充
- **本地映射记忆**：记住同网站字段映射，提高后续匹配准确率
- **JSON 迁移**：导出/导入全部资料版本，方便换电脑备份
- **平台适配增强**：内置牛客、智联、BOSS、北森、Moka 常见字段别名
- **隐私友好**：无网络请求、无埋点、无远程脚本、资料仅保存在本地浏览器

## 安装插件

1. 下载本项目源码，或下载 Release 中的 zip 包
2. 如果是 zip 包，先解压
3. 打开 Chrome 浏览器，进入：`chrome://extensions/`
4. 打开右上角“开发者模式”
5. 点击“加载已解压的扩展程序”
6. 选择包含 `manifest.json` 的项目目录
7. 浏览器右上角出现插件图标后，即安装完成

> 注意：不要选择 zip 文件本身，要选择解压后的文件夹。

## 使用流程

1. 点击浏览器右上角插件图标
2. 在弹窗中录入或编辑个人资料
3. 也可以点击“解析简历”，导入 `.txt` / `.md` / `.json` 文件生成资料版本
4. 在“当前资料版本”中切换版本，解析结果也可以继续编辑
5. 打开网申页面
6. 点击“打开安全侧边栏”
7. 先点击网页中的目标输入框，再点击侧边栏中的资料项
8. 填充后人工核对，人工保存或提交

## 简历解析

当前解析逻辑完全在本地浏览器运行，支持：

- `.txt`
- `.md`
- 插件导出的 `.json`

解析器会尝试提取：

- 姓名、手机号、邮箱、微信
- 政治面貌、出生日期、求职意向
- 教育经历
- 实习经历
- 项目经历
- 获奖证书
- 自我评价

PDF 和 DOCX 文件不会上传到任何服务器。为了保持无网络依赖和源码轻量可审计，当前版本不直接解析 PDF/DOCX 正文。建议先将 PDF/DOCX 简历另存为纯文本，或复制简历正文到 `.txt` 文件后导入。

## 本地智能识别

插件融合了智能识别表单的使用体验，但所有逻辑都在本地完成：

- **页面字段扫描**：扫描当前页面可填写控件
- **填充前预览**：展示“页面字段 -> 资料字段 -> 拟填内容”
- **置信度提示**：区分记忆、高、中、低置信匹配
- **本地映射记忆**：用户逐项填充或确认填充后，把“当前网站字段特征 -> 资料字段”保存在 `chrome.storage.local`

映射记忆不上传服务器，不记录投递行为，也不会触发表单提交。

## 平台兼容

当前版本采用“通用 Web 表单适配 + 平台字段别名增强”：

- 牛客：姓名、手机、邮箱、投递岗位、院校、专业、经历描述等
- 智联招聘：姓名、手机、邮箱、现居地、期望城市、期望薪资、学校、公司、职位等
- BOSS 直聘：求职岗位、期望地点、期望薪资、教育、项目等
- 北森：`italent` / 北森常见字段名和表单容器识别
- Moka：Moka 常见字段名和表单容器识别
- 企业官网：通用 `label` / `name` / `id` / `placeholder` / `aria-label` 识别

安全侧边栏模式对平台依赖最低，只要当前聚焦的是普通输入框、文本域、原生下拉框或可编辑文本区域，就可以逐项填入。

对于自定义下拉、日期弹窗、城市级联选择器等复杂控件，插件不会模拟打开弹窗或连续点击选项，建议人工选择。

## 风控边界

项目中没有以下逻辑：

- 自动提交表单
- 自动点击保存
- 自动点击下一步
- 自动翻页
- 自动投递
- 验证码绕过
- 页面打开后静默自动填充
- 远程脚本加载
- 用户数据上传

批量场景也会先展示扫描预览，由用户勾选确认后再写入字段。

## 权限说明

`manifest.json` 仅声明：

```json
{
  "permissions": ["storage", "activeTab"]
}
```

- `storage`：保存用户本地资料、多版本配置和本地字段映射记忆
- `activeTab`：用户主动点击插件后，与当前标签页通信并打开侧边栏或执行填充

项目不声明 `host_permissions`，不使用 `<all_urls>`，不请求网络权限。

## 技术实现

- Chrome Manifest V3
- 原生 HTML + CSS + JavaScript
- `chrome.storage.local` 本地持久化
- 多资料版本管理
- 本地启发式简历文本解析
- Shadow DOM 安全侧边栏
- DOM label 优先匹配策略
- 本地域名字段映射记忆
- 填充前扫描预览和置信度评分
- 原生 `select` 下拉框按 `option` 文本匹配
- 对常见受控表单触发 `input` / `change` 事件

## 上传到 GitHub

### 方式一：网页上传

1. 登录 GitHub
2. 点击右上角 `+`，选择 `New repository`
3. 填写仓库名，例如 `chrome-autumn-form-filler`
4. 选择 `Public`
5. 不要勾选 “Add a README file”，因为项目里已经有 README
6. 创建仓库
7. 点击 `uploading an existing file`
8. 把本项目文件夹里的所有文件拖进去
9. 点击 `Commit changes`

### 方式二：命令行上传

在项目目录中执行：

```bash
git init
git add .
git commit -m "feat: initial chrome autumn form filler"
git branch -M main
git remote add origin https://github.com/你的用户名/chrome-autumn-form-filler.git
git push -u origin main
```

如果你使用 SSH，把 remote 地址换成：

```bash
git remote add origin git@github.com:你的用户名/chrome-autumn-form-filler.git
```

## 发布 zip 下载包

如果想让别人直接下载插件：

1. 在 GitHub 仓库右侧点击 `Releases`
2. 点击 `Create a new release`
3. Tag 填：`v1.0.0`
4. Release title 填：`v1.0.0`
5. 上传打包好的 `chrome-autumn-form-filler.zip`
6. 点击 `Publish release`

别人下载 zip 后，解压并在 `chrome://extensions/` 中加载解压目录即可。
